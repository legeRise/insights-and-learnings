execution context 

a container that is created on function call 

it contains

1. variables
2. functions(if there any in function)
3. lexical enviroment ( what the function can use so
like a scope-chart)

so 

function abc(){
  var a = 10;
  var b = 12;
  function ad(){
     var c = 15;
  }
}

so now if abc() is called 

it creates a container that will have

1. variables   a and b 
2. function   ad()

and a lexical enviroment which just tells that above 
variables and function are accessible and also tells
that var c is not accessible because it is in the 
scope of ad() not abc()
